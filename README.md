# Green Mile Recycling System

## Overview
The **Green Mile Recycling System** is a web-based platform designed to manage and optimize recycling collection services. The system bridges the gap between customers, employees, and administrators by providing an integrated digital solution for scheduling, requesting, and tracking waste collection operations.

## Project Objectives
* Develop a web-based platform for submitting and managing recycling pickup requests with accurate, map-based locations
* Provide employees with tools to manage assigned requests, communicate with customers, and document each collection with photos
* Keep customers informed through real-time notifications, request status tracking, and live vehicle tracking
* Integrate an AI image classification model (TensorFlow.js) that identifies the type of recyclable material from an uploaded photo
* Protect user accounts and data using JWT authentication, role-based access control, and secure coding practices
* Give administrators a centralized dashboard to manage users, materials, schedules, and reports
